# examples

Grab any screenshot with small text (taskbar, file lists, IDE panels,
dense tables) and run:

    ../.venv/bin/python ../scripts/glyphboost.py your_screenshot.png

Then compare: read the small text in `your_screenshot.png` yourself
(squint), vs. what's in `your_screenshot_probe/crop_00.png`.

Example outputs (annotated.png, report.json, crops) land next to your
image in `your_screenshot_probe/`.
